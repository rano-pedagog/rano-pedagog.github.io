# Рано Шавкатовна Аминджанова — педагог нулевого класса

Персональная страница-резюме. Статический сайт, публикуется на Vercel.

**Онлайн:** https://rano-pedagog.vercel.app

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | вся страница: разметка, стили и интерактивные игры (раздел `#igry`) |
| `rano-portrait.jpg` | портрет в первом экране |
| `sertifikat.jpg` | сертификат конкурса «Успешный педагог» |
| `festival.jpg` | фото с фестиваля «Инновация дошкольного успеха» |
| `pedagog-o-rabote.mp4` | видео: педагог о своей работе |
| `fragment-zanyatiya.mp4` | видео: фрагмент занятия |
| `nagrazhdenie.mp4` | видео: церемония награждения |
| `poster-*.jpg` | превью для видео |
| `favicon.svg` | иконка вкладки |

Правки вносятся напрямую в `index.html` — сборка не требуется.

Деплой: `npx vercel --prod` из этой папки.
